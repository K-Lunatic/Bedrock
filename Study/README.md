# 터틀넥으로 기초 복습하기

[학습 팩 내려받기](bedrock-foundations.tpack) · [과목별 정리](../README.md)

여섯 과목을 각각 4문항으로 묶은 총 24문항의 기초 확인 팩입니다. 문제와 해설은 이 저장소의 공개 요약에 근거해 새로 작성했습니다. 실제 과거 시험문항이나 교수님 강의자료를 복제한 팩은 아닙니다.

## 사용 방법

1. [Turtleneck](https://github.com/K-Lunatic/Turtleneck)이 설치된 로컬 Codex 또는 Claude Code에서 학습 팩을 첨부합니다.
2. “이 학습 팩을 가져와서 저장된 시험 목록을 보여줘”라고 요청합니다.
3. 원하는 과목을 고르고 “이 시험을 새로 풀게 열어줘”라고 요청합니다. 터틀넥의 웹 시험 화면에서 답을 입력하고 결과·해설을 확인합니다.

팩을 가져오기만 하면 풀이 화면이 자동으로 열리는 것은 아닙니다. 저장된 시험의 단순 열람과 새로 풀기를 구분하세요. 단순 열람은 읽기 전용일 수 있습니다.

| 과목 | 문항 수 | 공개 정리 |
|---|---|---|
| C언어 | 4 | [요약](../Study_project-C/README.md) |
| Java | 4 | [요약](../Java/README.md) |
| 자료구조 | 4 | [요약](../Data-Structures/README.md) |
| 컴퓨터구조 | 4 | [요약](../Computer-Architecture/README.md) |
| 운영체제 | 4 | [요약](../Operating-Systems/README.md) |
| 데이터베이스 | 4 | [요약](../Database/README.md) |

시험 식별자는 [exams.json](exams.json)에 있습니다. 다른 기기에서 처음 가져온 경우에도 이 목록의 시험을 골라 새 풀이를 만들 수 있습니다.

## 이 팩에 담긴 것

새로 작성한 공개 요약의 학습 분석, 개념별 연습문제·정답·해설·근거와 여섯 과목의 시험 세트가 들어 있습니다. 배포용 팩이므로 정답 정보도 내부에 있으며 보안 시험용 자료는 아닙니다. 공식 시험 화면은 풀이 단계에 맞춰 표시합니다.

계정·로그인 정보, 원본 강의 파일·교재 스캔·녹음, 실제 성적·제출물·개인 답안 기록은 넣지 않았습니다. 공개 요약 원문은 저장소의 과목별 README에서 읽을 수 있습니다.

## 확인한 것

별도 학습 공간에서 가져오기, 같은 팩 재가져오기, 여섯 과목 모두 새 풀이 만들기를 확인했습니다. 24문항의 객관식 정답·오답 판정과 공식 웹 시험 화면의 응답도 확인했습니다. Notability 필기는 미반영이며 운영체제 등은 실제 필기와 대조한 뒤 보강할 초안입니다.

문항은 첫 복습 범위이며 전체 과목의 이해도나 시험 대비 완료를 평가하지 않습니다.
