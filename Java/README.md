# Java

Java 1의 기본 문법·클래스·상속과 Java 2의 객체·문자열·컬렉션 학습을 한 흐름으로 통합했습니다. 실제 로컬 실습과 복습 메모에서 확인한 범위이며, 두 과목을 별도 폴더로 나누지 않습니다.

## 핵심 정리

### 1. 클래스와 객체

클래스는 상태와 동작을 정의하며 객체는 그 정의로 만들어진 개별 인스턴스이다. 생성자는 초기 상태를 구성하고, 인스턴스 필드와 클래스 전체가 공유하는 static 필드를 구분한다.

### 2. 상속과 다형성

부모 타입의 참조가 자식 객체를 가리킬 수 있다. 오버라이딩한 인스턴스 메서드를 호출하면 실제 객체의 구현이 실행된다. 생성자에서 super를 쓰는 경우와 일반 메서드에서 부모 구현을 호출하는 경우를 구분한다.

### 3. 동등성과 문자열

객체 참조의 ==는 같은 객체인지 비교하고, equals는 클래스가 정의한 동등성을 비교한다. equals를 재정의하면 같은 객체로 취급되는 값의 hashCode도 같아야 한다. String은 불변이므로 replace 결과를 사용하려면 반환값을 받아야 한다.

### 4. 컬렉션 선택

List는 순서와 중복을 다루고 Set은 중복 없는 원소를 다룬다. Map은 키와 값의 대응을 저장한다. HashSet의 순회 순서를 입력 순서라고 가정하지 않는다. getOrDefault는 키가 없을 때 사용할 값을 지정할 수 있다.

### 5. 예외와 자원

예외가 발생하면 해당 try 블록의 남은 문장을 건너뛰고 맞는 catch를 찾는다. 예외를 무시해서 잘못된 상태로 계속 진행하지 않는다. 파일이나 스트림처럼 닫아야 하는 자원은 try-with-resources 사용을 검토한다.

### 6. 게임·임베디드에 연결

상태·행동을 나누는 객체 모델과 이벤트 처리는 게임 설계에도 연결된다. Java가 모든 게임 엔진이나 MCU의 직접 구현 언어라는 뜻은 아니다. 목표 엔진·보드의 언어는 별도로 익히되 객체·컬렉션 개념은 재사용한다.
