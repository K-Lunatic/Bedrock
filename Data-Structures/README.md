# 자료구조

실제 C 실습의 연결 리스트·역순·스택 코드와 자료구조 복습 기록을 바탕으로 정리했습니다. 기존 과제 지문과 시험문항을 복사하지 않았습니다.

## 핵심 정리

### 1. 복잡도와 전제

빅오는 입력 크기에 따른 자원 증가를 나타낸다. 순차 탐색의 최악 시간은 O(n)이며 정렬된 배열의 이진 탐색은 O(log n)이다. 이진 탐색의 전제인 정렬 상태를 먼저 확인한다.

### 2. 배열과 연결 리스트

배열은 인덱스 접근이 빠르지만 중간 삽입·삭제 때 원소 이동이 필요할 수 있다. 연결 리스트에서 삽입 위치의 이전 노드를 이미 알면 링크 변경은 O(1)이지만 그 위치를 찾는 순회는 O(n)일 수 있다.

### 3. head와 이중 포인터

단일 연결 리스트의 첫 노드가 바뀌면 호출자의 head도 바뀌어야 한다. 새 head를 반환하거나 head의 주소를 이중 포인터로 전달할 수 있다. 노드를 삭제할 때는 다음 링크를 확보한 뒤 필요한 메모리를 해제한다.

### 4. 스택과 큐

스택은 나중에 넣은 원소를 먼저 꺼내는 LIFO이고, 큐는 먼저 넣은 원소를 먼저 꺼내는 FIFO이다. 원형 큐에서 한 칸을 비워 empty와 full을 구분하면 길이 N 배열의 저장 가능 원소는 N-1개이다.

### 5. 재귀와 상태 추적

재귀는 종료 조건과 더 작은 문제로의 진행이 필요하다. 연결 리스트 역순은 다음 노드 보관, 현재 링크 뒤집기, 이전·현재 포인터 이동을 반복한다. 빈 리스트와 원소 한 개인 경우도 확인한다.

### 6. 게임·임베디드에 연결

입력 이벤트를 큐에 모으고 실행 취소 기록은 스택으로 생각할 수 있다. 센서 스트림에는 크기가 제한된 링 버퍼를 검토한다. 선택할 때는 복잡도뿐 아니라 메모리 배치와 최악 처리 시간도 함께 본다.
