# C언어

예전 C 수업 메모와 자료구조 실습에서 확인한 내용을 바탕으로 다시 쓴 복습 노트입니다. Notability 필기 원문은 아직 반영하지 않았습니다.

## 핵심 정리

### 1. 자료형과 연산

정수 나눗셈에서 7 / 2는 3이다. 소수 결과가 필요하면 7.0 / 2처럼 피연산자 하나를 실수로 바꾼다. 자료형을 고를 때는 값의 범위와 표현 방법을 함께 본다.

### 2. 배열과 길이

배열 인덱스는 0부터 시작하며 길이가 n이면 마지막 유효 인덱스는 n-1이다. 배열을 함수 인자로 전달할 때 원소 개수도 함께 전달한다. 배열 매개변수에 sizeof를 써서 호출자의 배열 길이를 알아낼 수는 없다.

### 3. 포인터와 값 전달

C 함수의 인자는 값으로 전달된다. 호출자의 변수를 바꾸려면 그 주소를 넘기고, 함수에서 포인터를 역참조해 저장한다. 주소를 담은 포인터 자체와 포인터가 가리키는 값을 구분한다.

### 4. 메모리 수명

malloc으로 할당한 메모리는 성공 여부를 확인하고, 더 이상 쓰지 않을 때 free로 해제한다. 해제한 메모리를 다시 읽거나 쓰지 않는다. 지역 자동 변수의 주소를 반환해 수명이 끝난 객체에 접근해서도 안 된다.

### 5. 제어 흐름과 디버깅

C에는 do-while이 있지만 until이라는 반복문은 없다. 입력 성공 여부, 반복문의 종료 조건, 배열 경계를 먼저 확인한다. 컴파일 경고를 읽고 작은 입력부터 상태를 추적한다.

### 6. 게임·임베디드에 연결

게임 객체나 센서 샘플의 구조체, 고정 크기 입력 버퍼를 생각하며 복습한다. 시간에 민감한 반복 처리에서는 할당과 해제 시점이 동작에 미치는 영향도 살펴본다. MCU 레지스터 접근과 CPU별 동작은 보드 설명서로 별도 확인한다.
