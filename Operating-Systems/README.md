# 운영체제

과거 운영체제 수강은 확인했으나 Notability 필기를 읽지 못했습니다. 아래는 실제 과목 필기를 복원한 내용이 아니라 게임·임베디드 학습을 위한 기초 복습 초안입니다.

## 핵심 정리

### 1. 프로세스와 스레드

프로세스는 실행 중인 프로그램의 자원과 실행 상태를 다루는 단위이다. 같은 프로세스의 스레드는 주소 공간을 공유하지만 각자의 실행 흐름과 스택을 가진다.

### 2. 스케줄링과 대기

여러 실행 흐름이 한정된 CPU 시간을 나누어 쓴다. 바쁜 대기는 조건을 계속 검사하며 CPU를 소비하고, 블로킹 대기는 조건이 만족될 때까지 실행을 쉬게 할 수 있다. 문맥 교환에는 상태 저장·복원 비용이 든다.

### 3. 경쟁 상태와 임계 구역

공유 값의 읽기·수정·저장을 여러 실행 흐름이 겹쳐 수행하면 갱신을 잃을 수 있다. mutex는 임계 구역에 동시에 들어가는 것을 제한한다. volatile만으로 복합 연산의 원자성이나 상호 배제가 보장되지는 않는다.

### 4. 가상 메모리

가상 주소는 주소 변환을 거쳐 물리 메모리에 대응된다. 페이지 테이블은 매핑을 관리하고 TLB는 주소 변환 정보를 캐시한다. 페이지 폴트는 디스크 읽기와 항상 같은 뜻은 아니며 유효성·접근 조건 등을 확인하는 처리로 이어진다.

### 5. 파일과 자원 수명

파일·소켓·잠금 같은 자원을 사용한 뒤 해제해야 한다. 실패 경로에도 해제 순서를 둔다. 동시에 접근하는 경우에는 데이터 보존과 동기화 조건을 별도로 설계한다.

### 6. 게임·임베디드에 연결

게임에서는 프레임을 막는 I/O와 공유 상태 접근을 살펴본다. ESP-IDF에는 FreeRTOS가 통합되어 있으므로 태스크와 큐·동기화를 공부할 때 운영체제 개념을 연결할 수 있다. MCU가 일반 PC 운영체제와 같은 가상 메모리 모델을 가진다고 가정하지 않는다.
